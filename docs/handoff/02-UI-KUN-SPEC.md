# Kun 风格 UI 规范 · TickFlow v1.13.0

> 参考图：`reference/images/01-settings-sidebar.png`、`02-main-shell.png`、`03-appearance-controls.png`、`04-appearance-schemes.png`
> 说明：只借视觉语言与设置信息架构，**不复制 Kun 的 AI 业务、Logo、品牌资产**。

---

## 1. 设计意图

一句话：**深海军蓝工作台 + 低对比层次 + 天空蓝强调 + 彩色图标分组 + 大输入区**。

- 背景不是纯黑，是带蓝的深色（#0A1220 附近），卡片比背景亮一档，靠 1px 边框分层。
- 强调色是天空蓝（#4C9AFF / #6FB6FF），只用于选中、主按钮、滑杆、开关、焦点环。
- 图标不是线性灰，而是**彩色方块/彩色线性图标**，承担分组识别。
- 圆角克制：卡片 12–14，控件 8，标签 999；不使用大圆角“果冻”。
- 阴影很轻，主要靠边框和明度差；不发光、不玻璃拟态堆叠。
- 信息密度中等：侧栏 36–40 行高，卡片 16–20 padding，正文 13–14px。

- 卡片：深色面板，1px 边框，圆角 12，padding 20–24。

- 说明文字 11–12px 灰；“主页点击涟漪”同样一行开关。

### 2.4 配色方案（04）

- 页面头部：左侧圆角方形图标（48×48，紫色渐变/描边），标题“外观”20px，副标题“主题、文字大小和界面配色。”；右上“修改会自动生效”幽灵按钮。

- 当前方案在卡片区右上角显示“当前：晴空蓝白 · 深色”。

### 3.3 左侧栏

- 品牌区：28×28 蓝色渐变方块（“刻”字）+ “刻度 / TickFlow” + 版本小字。
- 一级动作：“快速添加” 主按钮（蓝色，高 34）。
- 分组：
  - **工作台**：收件箱、今天、未来 7 天、全部、已完成
  - **视图**：时间轴、日历、四象限、习惯、统计、进程
  - **工具**：愿望、专注、命令面板
  - **底部**：外观、设置、帮助
- 分组标签：11px，`--text-3`，字距 0.8，左 10px。
- 菜单项：高 36，圆角 8，左 10px；图标 18px（彩色或 `--text-2`）；文本 13px。
- 选中：背景 `--accent-soft`，文本 `--text`，左侧 2px 蓝色竖条（或整行蓝灰底，二选一，统一）。
- 悬停：背景 `--panel-2`；150ms。
- 徽章：右侧计数，11px，`--text-3`；0 不显示。
- 底部配置：头像/本地配置 + “本地数据”小字；点击开配置浮层。

### 3.4 顶栏

- 左：面包屑（“工作台 / 今天”）或页面标题；返回按钮仅子页。
- 中：搜索框（宽 220–280，高 32，圆角 8，`Ctrl+K` 聚焦）。
- 右：视图操作（筛选/排序/更多）+ 配置徽章。
- 高度 48；底边 1px `--border`；背景 `--bg`（可轻微透明 + blur，但不要玻璃堆叠）。

### 3.5 右侧图标栏

- 44px 宽，垂直居中偏上；每个按钮 32×32，圆角 8，图标 18px。
- 顺序：搜索、命令面板、专注、外观、设置、收起。
- 悬停：`--panel-2` + 1px `--border`；tooltip 在左侧。
- 1060 宽以下默认隐藏，顶栏“更多”里提供入口。

### 3.6 底部状态栏

- 高 28；背景 `--panel`；上边 1px `--border`；12px 字。
- 左：专注开关（小胶囊）+ 当前任务数。
- 中：同步状态（本地/双岛同步中/顶部岛关闭）。
- 右：版本 `v1.13.0` + 编码/环境（可省略）。
- 不换行；1060 下隐藏中段文案，只留图标 + 数字。

## 4. 内容区

### 4.1 页面头

- 标题 20px/600；副标题 12.5px `--text-2`；右侧操作按钮。
- 与内容间距 16–20。
- 不使用大色块标题；标题本身是识别点。

### 4.2 卡片

- 背景 `--panel`；1px `--border`；圆角 12；阴影 `--shadow-1`。
- padding 16–20；卡片间 12–16。
- 卡片内不再套卡片；用留白 + 发丝线分组。
- 卡片标题 14px/600；说明 12px `--text-2`。

### 4.3 快速添加 / Composer

- 参考 Kun composer：宽 100%，最大 896；圆角 14；背景 `--panel`；1px `--border`；聚焦时 `--accent` 边框 + 3px `--accent-soft` 外环。
- 输入 14px；占位“描述你想添加的任务…”；最小高 52。
- 预览行：固定 28px 高，chip 12px；无内容时 `visibility:hidden` 占位，不抖动。
- 底行：左 `+`（清单）、优先级、日期 chip；右“添加”主按钮 + 快捷键提示 `Enter`。
- 粘性 chip（今天/明天/高优先级）放在输入框下方，22px 高，圆角 999。
- 连续添加：焦点不丢，列表局部刷新，侧栏计数同步。

### 4.4 任务行

- 高 40–44；左 18px 圆环；标题 13.5px；元信息 11.5px `--text-2`。
- 优先级左侧 2.5px 色条（不高于行高 60%）。
- 行尾“⋯”30×30，悬停/选中/聚焦时出现。
- 完成态：标题 `--text-2` + 删除线；圆环填充 `--accent`；不立刻消失。
- 选中/菜单打开：背景 `--panel-2`；1px `--border-strong`。

### 4.5 愿望卡

- 卡片 12 圆角；左 4px 色条；标题 13.5/600；描述 12px 两行截断；底部 chip（分类/日期/状态）。
- 已实现：色条 50% 透明 + 标题 `--text-2` + 绿色“已实现 ✓”chip；**不给整卡 opacity**（会压暗元信息）。
- 网格：1400 下 3 列，1060 下 2 列；间距 12。

### 4.6 抽屉 / 弹窗 / 命令面板 / Toast

- 抽屉：右侧 400–440；背景 `--panel`；左 1px `--border`；标题 15/600；底部操作固定。
- 弹窗：最大 720；背景 `--panel`；圆角 14；遮罩 `rgba(4,8,16,.55)`；进入 180ms ease-out。
- 命令面板：560×468；背景 `--panel`；圆角 12；搜索 14px；结果行 36；选中 `--accent-soft`。
- Toast：底部居中；背景 `--text` / 深色反色；12px；圆角 8；2.4s；最多 3 条。
- 所有浮层：Esc 关闭；点外部关闭；焦点环可见。

### 5.1 布局

- 全屏页面（不是小弹窗）：左 248px 分类栏 + 右内容；顶部返回 + 标题。

- 1060 下左栏 220；<900 左栏变横向 chip 行。

### 5.2 分类与图标

| 分类 | 图标色 | 包含项 |
|---|---|---|
| 常规 | 蓝 | 通用、启动、语言、本地配置 |
| 外观 | 紫 | 主题、配色方案、字号、内容宽度、交互特效 |
| 通知 | 琥珀 | 提醒、声音、免打扰 |

### 5.3 外观页（重点）

- 顶部：“外观”20px + 副标题 + 右上“修改会自动生效”。
- **主题**卡：3 张卡（浅色/深色/跟随系统）；每张卡内是迷你窗口预览；选中 2px 蓝边 + 勾；说明“配色方案会自动切换到对应版本”。
- **配色方案**卡：4 列网格；9 张（8 预设 + 自定义）；每张卡浅/深双预览；选中蓝边 + 勾；右上显示“当前：晴空蓝白 · 深色”。
- **文字与布局**卡：
  - 字体大小：A 小 — 滑杆 — A 大；步进器 82%；范围 70–120。**82% = v1.12 正文 13.5px 的基准**，默认不改变现有视觉；100% 才放大。
  - 对话/内容宽度：窄 — 滑杆 — 宽；步进器 896px；范围 640–1200。
- **交互特效**卡：
  - 侧栏/顶栏跟随鼠标高光：开关；说明。
  - 强调色：色块 + hex 输入 + “默认”；色带 7 档；默认跟随方案。
  - 主页点击涟漪：开关；说明。
- **自定义配色**（P1 完整）：背景/面板/边框/强调色四个色块 + hex；对比度提示；重置。
- 所有修改即时生效；不需要“保存”按钮；写入 Store + localStorage。

## 6. 组件规格

### 6.1 按钮

| 类型 | 高 | 圆角 | 背景 | 文本 |
|---|---|---|---|---|
| 主按钮 | 32–34 | 8 | `--accent` | `--accent-ink` |
| 次按钮 | 32 | 8 | `--panel-2` | `--text` |
| 幽灵 | 30 | 7 | transparent | `--text-2` |
| 危险 | 30 | 7 | transparent | `--danger` |
| 图标按钮 | 30–32 | 8 | transparent | `--text-2` |

- hover：主按钮亮度 +4%；次按钮 `--panel-3`；幽灵 `--panel-2`。
- active：`transform: scale(.97)`；只动 transform。
- 禁用：opacity .45；cursor not-allowed。
- 焦点：2px `--accent` + 2px offset。

### 6.2 输入 / 搜索

- 高 32–36；圆角 8；背景 `--bg` 或 `--panel-2`；1px `--border`。
- 聚焦：边框 `--accent` + 3px `--accent-soft`。
- placeholder `--text-3`；字号 13。
- 搜索框带 16px 放大镜；清空按钮 24。

### 6.3 开关 / 滑杆 / 步进器

- 开关：40×22；关闭 `--panel-3`，开启 `--accent`；圆点 18；180ms。
- 滑杆：轨道 4px `--panel-3`；已填充 `--accent`；thumb 14 白/蓝；hover 16。
- 步进器：高 32；圆角 6；背景 `--panel-2`；`−/＋` 24×24；数值 13 tabular-nums。

### 6.4 主题卡 / 配色卡

- 主题卡：高 120–140；内部迷你窗口 16:9；选中 2px `--accent` + 右上 18px 勾。
- 配色卡：高 150–180；内部上下/左右双预览；名称 13/600；描述 11.5 `--text-2`；选中 2px `--accent` + 勾。
- hover：边框 `--border-strong`，translateY(-1px)（reduced motion 关闭）。

### 6.5 灵动岛（底部）

- 保留 v1.12 的三态与尺寸；只换皮：
  - 背景 `--panel`/深色玻璃；1px `--border`；圆角 14；阴影 `--shadow-3`。
  - 收起 560×40；展开 560×342；z=30。
  - 主按钮 `--accent`；次按钮 `--panel-2`；提醒态 `--danger` 边框。
  - 与状态栏/内容底部留 96px 安全区。

## 7. 颜色使用

- 背景层级：`--bg` < `--panel` < `--panel-2` < `--panel-3`；不要用纯黑/纯白。
- 文本：`--text` 正文、`--text-2` 次要、`--text-3` 元信息；`--text-3` 对 `--panel` ≥4.5。
- 强调：`--accent` 只用于选中/主按钮/滑杆/开关/焦点；不要整页大面积铺。
- 语义：`--success` 已实现/完成；`--warning` 到点/权限；`--danger` 删除/逾期。
- 彩色底上的文字：深色模式用近黑 `--accent-ink`；浅色模式用白。禁止 `#fff` 硬编码。
- 禁止紫→蓝渐变；渐变只允许同色系 `color-mix`。
- 禁止彩色外发光；阴影用中性色。

## 8. 动效

- 时长：120ms hover/按压；180ms 卡片/浮层；240ms 抽屉/页面；300ms 岛展开。
- 曲线：`cubic-bezier(.23,1,.32,1)` 入口；`cubic-bezier(.32,.72,0,1)` 抽屉；关闭临界阻尼。
- 只动 `transform/opacity/color/border-color/box-shadow`。
- 禁止 `transition: all`、`ease-in`、`scale(0)`。
- 每个视图只演一次入场；列表错峰 22ms，上限 8 条。
- `prefers-reduced-motion: reduce`：去掉位移/缩放，保留透明度；涟漪/高光关闭。

## 9. 交互特效

### 9.1 侧栏/顶栏跟随高光

- 鼠标在侧栏/顶栏移动时，在指针位置绘制 240px 径向渐变（`--accent` 8%→0）。
- 用 CSS 变量 `--mx/--my` + `radial-gradient`；节流 rAF；120ms 缓动。
- 只在 hover 区域显示；离开淡出 180ms。
- 设置开关 `appearance.highlight`；reduced motion 关闭。

### 9.2 主页点击涟漪

- 在内容区空白处点击，绘制一个 480ms 扩散圆环（`--accent` 18%→0），最大 320px。
- 最多同时 3 个；不拦截点击。
- 设置开关 `appearance.ripple`；reduced motion 关闭。
- 只在“今天/收件箱”等空态/背景区域生效，不在输入/按钮上触发。

## 11. 可访问性

- 正文/元信息对比度 ≥4.5；非文本图形 ≥3:1。
- 所有可点元素键盘可达；`:focus-visible` 2px 主色 + 2px offset。
- 图标按钮有 `aria-label`；开关有 `role="switch"` + `aria-checked`。
- `prefers-reduced-motion` 全量降级。
- 中文输入法组字不误触 Enter（`isComposing` 保护）。

| 深蓝底 + 一档亮面板 + 1px 边框分层 | 纯黑 + 大阴影 + 发光 |
| 天空蓝只做强调 | 整页蓝色/紫蓝渐变 |
| 彩色小图标做分组识别 | 每个标题上放彩色方块 |
| 12–14 圆角卡片 | 全部 20+ 大圆角/果冻 |
| 13–14px 正文、12px 次要 | 10px 以下正文 |
| 留白 + 发丝线分组 | 卡片套卡片 |
| 动效只做 transform/opacity | `transition: all` / `ease-in` |
| 颜色走 token | 组件里写裸 hex |
