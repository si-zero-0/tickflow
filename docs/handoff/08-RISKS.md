# 风险、取舍与回滚 · TickFlow v1.13.0

---

## 1. 高风险

### R1 双窗口同步出现“双 Store”
- **风险**：顶部岛直接读 localStorage 并写回，导致任务完成两次、提醒重复、主题不同步。
- **规避**：主窗口唯一 Store；顶部岛只收快照、只发 action；主进程不缓存业务数据。
- **验证**：`m3-sync.test.mjs`；5 条同分钟提醒；双端同时勾选。
- **回滚**：关闭 `m3.enabled`，底部岛恢复 v1.12。

### R2 提醒重复/丢失
- **风险**：两端都跑 30s 轮询；或 8s 收起清队列；或 `notifiedOn` 被顶部岛误写。
- **规避**：轮询只在主窗；`notifiedOn` 只由主窗写；顶部岛只“确认当前条”；8s 收起不清队列；同一 taskId 去重。
- **验证**：5 条队列 + 8s 收起 + 知道了逐条 + snooze。
- **回滚**：关闭顶部岛。

### R3 主题迁移导致老用户数据/视觉异常
- **风险**：旧 `theme/accent` 被删；迁移把 dark 变 light；对比度不达标。
- **规避**：旧字段保留一年；迁移前快照；提供“恢复 v1.12 外观”；9×2 对比度单测。
- **验证**：构造 v1.12 数据导入；快照回滚；6 个旧主题映射。
- **回滚**：恢复旧 theme/accent 字段读取。

### R4 顶部岛点击穿透/焦点
- **风险**：`focusable:false` 导致按钮点不到；或点击抢走当前应用焦点；或透明窗口黑边。
- **规避**：P0 用“小窗口贴合岛体”，不做大透明画布；所有按钮在窗口内；`showInactive()`；`hasShadow:false`；`backgroundColor:'#00000000'`。
- **验证**：Electron 点击/焦点/截图；切换应用时焦点不跳。
- **回滚**：关闭顶部岛。

### R5 多显示器/DPI/全屏
- **风险**：岛跑到屏幕外；125%/150% 尺寸错；全屏应用被遮挡。
- **规避**：P0 只支持主屏 + DIP；`setBounds` 夹取工作区；P1 再做多屏/全屏检测。
- **验证**：1060/1400/4K；125%/150%；拔插显示器。
- **回滚**：恢复主屏居中。

## 2. 中风险

### R6 视觉重构范围蔓延
- **风险**：一次改 12 个视图 + 所有组件，回归面巨大。
- **规避**：先 token + 主壳 + 设置 + 外观，再逐组件替换；每步 `verify/test`；旧样式保留兼容层，最后删。
- **验证**：12 视图截图矩阵。
- **回滚**：按组件回退 CSS/类名。

### R7 字号/宽度破坏布局
- **风险**：`font-size` 全局放大导致侧栏/状态栏/岛溢出；`contentWidth` 过窄导致表格/日历错位。
- **规避**：字号用 `rem` + 容器 `clamp`；宽度 `max-width` + 最小 640；1060/1200 断点；关键容器 `min-width:0`。
- **验证**：70/82/100/120 × 640/896/1200。
- **回滚**：恢复 82/896。

### R8 对比度
- **风险**：9 套配色里浅色主题的 `--text-3` 或主按钮白字掉到 4.5 以下。
- **规避**：`schemes.json` 先跑测试；渐变按钮不用白色提亮顶部（v1.12 DEF-01 教训）；彩色底文字用 `--accent-ink`。
- **验证**：`appearance.test.mjs` 9×2；截图抽查。
- **回滚**：调 text/panel，不改 token 名。

### R9 性能
- **风险**：双窗口 + 高频 IPC + 每帧重绘，内存/CPU 上升。
- **规避**：快照 50ms 合并；倒计时 1s；不可见窗口暂停；顶部岛不加载 `app.js`；`backgroundThrottling:false` 只给主窗。
- **验证**：内存增量 <80MB；同步 P95 <100ms；暖启动 <60ms。
- **回滚**：关闭顶部岛。

### R10 设置页重建/丢滚动
- **风险**：切分类重新 `innerHTML` 整页，滚动位置丢失，输入焦点丢失。
- **规避**：外层壳只建一次；右栏切换只替换内容；保存 `scrollTop`；主题切换只改 class/变量。
- **验证**：设置页滚动到底 → 切 3 次主题/分类 → 位置保持。
- **回滚**：恢复单页设置。

## 3. 低风险

- R11 顶部岛图标/字体缺失：用内联 SVG/系统字体，不依赖外部资源。
- R12 托盘/快捷键冲突：注册失败要提示，不静默；保留 `Ctrl+Alt+Space`。
- R13 顶部岛窗口残留：`will-quit` 统一销毁；单实例。
- R14 透明窗口黑边：`hasShadow:false` + `backgroundColor:'#00000000'`；截图检查四角。
- R15 旧插件受影响：不改 `TF.ext`/`registry` 协议；插件数据 key 不变。

## 4. 取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| 顶部岛大画布 vs 小窗口 | **小窗口** | P0 避免点击穿透/命中区复杂度；体验足够 |
| 双 Store vs 主窗唯一 Store | **主窗唯一** | 不会重复提醒/双写；代价是主窗必须存活（托盘） |
| 12 个岛内页面 | **不做** | 与任务管理主线偏离；M3 只做任务/提醒/专注 |
| 9 方案 vs 6×6 | **9 方案** | 参考图要求；旧主题做映射，不双轨维护 |
| 完整自定义编辑器 | **P1** | P0 只做 4 个颜色覆盖，先验证 |
| 顶部岛默认开 | **默认关** | 成本最高；关闭时保证 v1.12 回退 |

## 5. 回滚清单

1. `settings.m3.enabled=false` → 销毁顶部岛；底部岛不变。
2. `appearance` 回退：恢复旧 `theme/accent` 字段；或“恢复 v1.12 外观”按钮。
3. 数据：迁移前 `Store.snapshot(true)`；`restoreSnapshot()`。
4. 代码：按 Phase 记录的文件清单回退；不要 `git reset --hard`（本包无 git）。
5. 构建：`npm run stage` 重建；旧 `src/main/stage` 不保留。
