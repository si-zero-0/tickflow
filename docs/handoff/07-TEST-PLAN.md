# 测试与验收计划 · TickFlow v1.13.0

## 7. 缺陷分级

- **S1**：数据丢失/无法启动/主流程不可用 → 必须修。
- **S2**：核心功能错误/提醒重复或丢失/布局严重错位 → 必须修。
- **S3**：视觉细节/对比度边际/死代码 → 可修则修，记录。
- **S4**：建议/优化 → 记录。
