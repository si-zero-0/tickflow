# TickFlow v1.13.0 · 产品需求文档（PRD）

> 版本：1.13.0（增量）
> 基线：1.12.0（已交付，45 条单测）
> 日期：2026-11-20
> 状态：待实现
> 关联：`02-UI-SPEC.md`、`03-M3-DUAL-ISLAND.md`、`04-DESIGN-TOKENS.md`

---

## 1. 一句话

把 TickFlow 从“可用的本地任务工具”升级为“**深海军蓝工作台**”：视觉语言参考现代桌面应用（只借风格与设置 IA，不复制 AI 业务），同时加入 **M3 双岛**（底部主岛保留 + 顶部迷你岛），两套 UI 共享一份状态。

## 2. 背景与问题

v1.12 已经完成 6 主题 × 6 强调色、愿望模块、快速添加、灵动岛三态。但：

1. 视觉仍偏“传统任务列表”，缺少参考应用那种**深色工作台 + 彩色图标分组 + 大输入区**的专注感。
2. 设置分散在弹窗里，外观只有“主题卡 + 强调色圆点”，没有字号、内容宽度、交互特效、配色方案。
3. 底部岛只能在同一窗口内，无法在写代码/浏览网页时**始终可见**；顶部迷你岛可以解决“不打断当前应用”的提醒与快捷操作。
4. v1.12 的 `app.css` 还留有旧颜色 token 与旧主按钮渐变，存在 latent footgun（I-17）。

## 3. 目标与非目标

### 3.1 目标

- G1：主壳、设置、外观、组件统一为现代桌面风格；不改业务语义。
- G2：9 套配色 × 浅/深/系统；字号与内容宽度可调；强调色/高光/涟漪可调。
- G3：M3 双岛：顶部迷你岛可开关、三态、与底部主岛同步；提醒不重复。
- G4：保持本地优先、零后端、零新运行时依赖。
- G5：12 个视图、任务/愿望/专注/统计/导入导出/命令面板无回归。

### 3.2 非目标

- 不做账号、云同步、支付、团队协作。
- 不做参考应用的 AI 功能：模型供应商、MCP、子代理、记忆、终端、手机、代码工作区。
- 不做完整的 12 个岛内业务页（音乐/邮箱/AI 额度/日程/系统/天气/进程）；M3 只做任务/提醒/专注相关的岛。
- 不做移动端；不换框架（不引入 React/Vue/Tailwind）。
- 不做其品牌资产、Logo、字体授权；只做视觉语言近似。

## 4. 用户与场景

| 用户 | 场景 | 诉求 |
|---|---|---|
| 个人任务管理者 | 每天在电脑前工作，任务散落在多个 app | 一眼看到今天/当前任务；不打断当前应用就能完成/推迟 |
| 深度工作者 | 写代码/写文档时不想切窗口 | 顶部迷你岛常驻；到点提醒；一键专注 |
| 外观敏感用户 | 长时间看深色界面 | 深海军蓝、低对比层次、可调字号/宽度、可换配色 |
| 老用户 | 已用 v1.12，有本地数据 | 升级不丢数据；旧主题映射到新方案；不喜欢可回退 |

## 5. 当前基线（v1.12.0）

- 任务：收件箱/今天/未来 7 天/全部/已完成/时间轴/日历/四象限/习惯/进程/统计。
- 愿望：独立集合、卡片网格、统计、筛选、排序、编辑、实现、转任务。
- 快速添加：8 日期 + 3 时间 + 优先级 + 标签 + 清单；实时预览；连续录入。
- 灵动岛（底部）：收起/展开/提醒；R1–R5；今日 5 条；6 操作；队列 ≤20；8s 收起；可关。
- 主题：6 主题 × 6 强调色；设置预览；持久化。
- 其他：命令面板、快速捕获、抽屉、行菜单、导入/导出、快照、本地配置。
- 质量：`verify` 8/8、`npm test` 45/45、12 视图回归。

## 8. 关键决策

### 8.1 配色系统替换而不是叠加

v1.12 是 `theme`（6 主题）+ `accent`（6 强调）。v1.13 改为：

```
appearance.mode   = light | dark | system
appearance.scheme = kun-default | sky | parchment | mint | sakura | dusk | amber | ink | custom
appearance.custom = { bg, panel, border, accent }
appearance.fontSize = 70..120
appearance.contentWidth = 640..1200
appearance.accentOverride = null | hex
appearance.highlight = true
appearance.ripple = true
```

旧字段保留兼容，迁移映射：

| 旧 theme | 新 scheme | 旧 accent | 新 accent |
|---|---|---|---|
| graphite | kun-default（dark） | blue | 方案默认 |
| night | ink（dark） | cyan | 方案默认 |
| tundra | mint（dark） | green | 方案默认 |
| dawn | parchment（light） | purple | 方案默认 |
| mist | sky（light） | orange | 方案默认 |
| paper | parchment（light） | rose | 方案默认 |

> 旧 `accent` 若用户显式改过，写入 `appearance.accentOverride`，避免“升级后强调色变了”。

### 8.2 主窗口持有唯一 Store

M3 不新开一套 Store。主窗口是唯一 owner；顶部岛是 projection：

```
主窗口 Store --snapshot(50ms throttle)--> main IPC hub --> 顶部岛 render
顶部岛 --action(complete/snooze/open/focus)--> main IPC hub --> 主窗口 Store
主窗口 --ack/state--> 顶部岛
```

好处：不会出现双端同时写 localStorage、提醒重复、主题不同步。代价：主窗口必须存活（最小化可以；关闭到托盘时隐藏不销毁）。

### 8.3 顶部岛默认关闭

M3 成本最高，默认关闭；设置里开启。关闭时底部岛与 v1.12 完全一致，保证回退。

## 10. 假设（实现者按此执行，不要停下来问）

1. 参考图是**视觉参考**，不是像素级还原；允许按 TickFlow 的信息架构调整。
2. 参考应用的 AI 功能与 TickFlow 无关，不实现；只借侧栏分组、彩色图标、卡片、外观页、滑杆、配色方案。
3. 9 套配色由 `schemes.json` 定义；允许实现时微调 hex 以保证对比度，但需记录。
4. 顶部岛默认关闭；主窗口关闭到托盘而不是退出，保证顶部岛可用。
5. 不引入新依赖；Electron 原生 API 足够。
6. 现有 12 视图与数据语义不变；只改视觉与新增岛。
7. **字号 82% 是 v1.12 正文字号（13.5px）的基准点**，不是 16px 的 82%；实现时 `--font-scale = fontSize / 82`，默认 82 保持现有视觉，100 才放大。
8. 8 个预设配色 + 1 个自定义；自定义先做“背景/面板/边框/强调色”四项，P1 再做完整编辑器。
