# 刻度 TickFlow · 设计系统

> 本文件是刻度 TickFlow 的**视觉与交互契约**。改动 UI 前先读它；新增样式只能扩展这里的 token，不得在组件里写裸值。
> 规则来源：Emil Kowalski 设计工程准则 + `pbakaus/impeccable` 反模式清单 + `Leonxlnx/taste-skill` 完成度门槛。

## 产品语气

- 工具感优先。**不做游戏化**：不加等级/经验/成就/标题画面；"游戏感"只体现在交付形态（单文件、免安装、双击即用）。
- 中文优先，文案短句，不用感叹号堆砌。
- 本地优先：无账号、无云端、无内购，界面上明确说明数据存在本机。

> **v1.12.0 起，颜色的唯一权威是 `css/theme.css`**。本表是它的文档化副本，两边必须逐字一致（`tests/theme.test.mjs` 与 `tests/core.test.mjs` 会算对比度、校验映射）。
> 组件里**只允许** `var(--…)`，不得新增裸 hex。

### 主题 × 明暗 × 强调色（三个正交维度）

`<html>` 同时维护四个属性，**主题名只表达身份，明暗由 `data-mode` 表达**：

| 属性 | 取值 | 说明 |
|---|---|---|
| `data-theme` | `graphite / night / tundra / dawn / mist / paper` | 只决定中性层级 |
| `data-mode` | `dark / light` | 由主题推导（graphite/night/tundra→dark，其余→light） |
| `data-accent` | `blue / cyan / green / purple / orange / rose` | 与主题正交 |
| `data-density` | `normal / compact` | 行高密度 |

组件补丁一律挂 `[data-mode="light"]`，**不要**再写 `[data-theme="light"]`（该值已不存在）。

### 6 种强调色

| accent | `--ac-d`（dark 底） | `--ac-l`（light 底） | `--ac2-d` | `--ac2-l` | 色相锚点 |
|---|---|---|---|---|---|
| `blue` 蓝 | `#5B8CFF` | `#3D6FE0` | `#8B6BFF` | `#7B4CE0` | 222° |
| `cyan` 青 | `#25C2D4` | `#0B7D8F` | `#3AA8E8` | `#1C7FB8` | 187° |
| `green` 绿 | `#2BD4A3` | `#0B8060` | `#57C46B` | `#2F8F45` | 162° |
| `purple` 紫 | `#A06BFF` | `#7B4CE0` | `#C86BD8` | `#9A45AC` | 265° |
| `orange` 橙 | `#F5A623` | `#A65F00` | `#F07B3C` | `#B85417` | 36° |
| `rose` 玫红 | `#FF5F7A` | `#D63A57` | `#F062A0` | `#B33A72` | 350° |

- `[data-accent]` **只出四个原子值**，再由 `[data-mode]` 映射成 `--ac / --ac2 / --ac-ink / --ac-soft`。不要给 `[data-accent]` 直接写 `--ac`，否则主题与明暗耦合。
- **`--ac-ink`（压在彩色底上的文字）**：dark `#0A0D12`（近黑，对 `#5B8CFF` 6.23:1）、light `#FFFFFF`（对 `#3D6FE0` 4.62:1，全组 ≥4.5）。所有"彩色底 + 文字"的落点必须用 `var(--ac-ink)`，**不要写 `#fff`**。
- 语义色随 **mode** 变（浅色须加深），不随 theme / accent 变：`--ok` `#2BD4A3`/`#0B8060`、`--warn` `#F5A623`/`#A65F00`、`--dan` `#FF5F7A`/`#D63A57`、`--p1/2/3` 同源。
- **禁用紫→蓝渐变**（AI slop）。渐变只允许同色系明暗，实现用 `color-mix(in srgb, var(--ac) …, #fff/#000)`，**不允许硬编码第二个色相**。
- 低透明度色（`--ac-soft`）是"色彩 wash"，不算实色填充；不要在它上面放低对比文字。
- 纸感主题偏中性暖灰（`#F2F1EE`），**不要回到米黄**（cream page 是 slop）。

### 主题层的边界（硬约束）

- `theme.css` **只出颜色**。`--r/--r2/--r3/--dw/--sb/--fs-*/--ease-*/--t-*` 仍由 `app.css` 与 `refresh.css` 负责——`theme.css` 最后加载，重定义会把 `@media (max-width:1080px){:root{--dw:360px}}` 的响应式结果永久覆盖。
- `--shadow` 不重定义：`refresh.css` 里是 `--shadow:var(--sh-3)`，变量延迟解析，`--sh-3` 变了它自动跟随。


## 字体与字号

字体栈：系统 UI 字体（`-apple-system, "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", …`）。**不引入 Inter 作为全局字体**。

语义字号阶——相邻角色步进必须 ≥1.25×，否则是"扁平层级"：

| token | 值 | 角色 |
|---|---|---|
| `--fs-h1` | 19px | 页面标题（顶栏 `<h1>`） |
| `--fs-h2` | 15px | 抽屉 / 弹窗标题（`<h2>`） |
| `--fs-h3` | 11.5px | 区块标签（`<h3>`，字距 0.9px） |
| `--fs-body` | 13.5px | 正文、任务标题 |
| `--fs-cap` | 12.5px | 辅助说明 |
| `--fs-micro` | 11px | 元信息、标签 |

- 标题必须用真实语义元素（`h1/h2/h3`），不要用 `div` 假装标题，也不要跳级。
- 数字统一 `font-variant-numeric: tabular-nums`。

## 层次与容器

- 阴影三级：`--sh-1` 卡片、`--sh-2` 悬浮、`--sh-3` 弹层。
- 圆角四级：`9 / 13 / 15 / 18`，控件 8–9，卡片 13，弹窗 15，大卡 18。
- **卡片里不再套卡片**：`.card .card, .card .stat` 去边框去底色，靠留白分组。
- 不用发光（glow）表达层级；去掉彩色外阴影，只留内高光 + 中性阴影。

## 灵动岛（v1.12.0）

窗口**底部居中**、距底 14px 的常驻组件，三态：

| 态 | 触发 | 形态 |
|---|---|---|
| `collapsed` | 默认 / 收起 / Esc / 点外部 / 8s 超时 | 40px 胶囊：状态点 + 当前任务（1 行省略）+ 右侧信息位 |
| `expanded` | 点胶囊 | 向上生长的面板（`max-height:min(60vh,100vh-96px)`，内容内部滚动）：当前任务卡 + 今日待办（≤5）+ 6 个操作 + 「打开全部待办 →」 |
| `remind` | 到点（`autoExpand` 开） | 面板换成提醒卡，边框高亮 + 上浮 2px；完成 / 10 分钟后 / 知道了 |

**当前任务判定 R1–R5**（`TF.pickCurrentTask`，纯函数）：R1 进行中的时段任务（取开始最晚）→ R2 已到点的点任务（取最晚）→ R3 今日未命中 R1/R2 的全部任务（优先级降序，同优取最新）→ R4 逾期兜底 → R5 空态。

- 状态点配色：R1/R2 `--warn`、R3/R4 `--ac`、R5 `--tx3`、今日全完成 `--ok`、提醒 `--dan`。
- 右侧信息位：R1 `mm:ss`（每秒刷新，`tabular-nums`）、R2 `逾期 N 分`、R3/R4/R5 `今日 N 项`。
- **收起时绝不写 `notifiedOn`**：该字段只由 `app.js` 的 30s 轮询写入，误清会导致同一任务重复提醒。
- `settings.island.enabled=false` → 隐藏并恢复右上角旧提醒卡；`autoExpand=false` → 到点只亮状态点 + 显示「N 条到点」，点胶囊才进提醒态。
- 共存：`body.island-on .content{padding-bottom:96px}`；toast 上移到 `--island-h + 24px`（岛展开时自动让位）；抽屉/弹窗打开时岛被压暗且不响应点击。


## 动效

- 曲线：`--ease-out cubic-bezier(.23,1,.32,1)`、`--ease-in-out`、`--ease-drawer cubic-bezier(.32,.72,0,1)`。
- 时长：`--t-fast 120ms`（hover/按压）、`--t-base 180ms`（卡片、弹层）、`--t-slow 240ms`（进度、抽屉 300ms）。
- 只动 `transform` / `opacity` / `color` / `border-color` / `box-shadow`；禁止 `transition: all`，禁止裸写时长。
- 入口一律 `ease-out`；**禁止 `ease-in`**、禁止 `scale(0)` 起点。
- 每个视图只演一次入场（`.view-enter`），任务列表用错峰入场（`.stagger`，22ms 步进，上限 8 条）。
- 键盘触发的操作（搜索、命令面板）不做开合动画。
- `prefers-reduced-motion: reduce` 下保留透明度过渡，去掉位移。

## 交互

- 所有可点元素 `:active { transform: scale(.96~.97) }`。
- 焦点环 `:focus-visible` 2px 主色 + 2px offset，鼠标点击不出现。
- 图标按钮 ≥30×30；文字按钮 `white-space: nowrap`（**不允许竖排折行**）。
- 横向位移只用于从属关系明确的方向；拖拽、进度、展开用纵向。
- 弹层锚定触发器展开，`transform-origin` 指向触发点。

## 组件约定

- **配置徽章**（侧栏顶部）：头像 + 名称 + 计数，点击展开配置切换浮层。
- **任务行**：18px 圆环复选框 + 标题 + 元信息；优先级用左侧 2.5px 色条，不用旗标；行尾只有一个「⋯」按钮（≥30×30，悬停/选中/聚焦时出现），改期、完成、删除、打开详情都走它。
- **完成不立刻消失**：勾选后留在原位划掉，点顶栏「刷新」才收起。
- **进程画布**：轨道色带铺满可视区；轨道下沿手柄可纵向拉伸（120–420px，双击复位）；连线按相对位置智能选择出入边。
- **时间轴**：未排时间的任务放在顶部「全天」条，不占整天。
- **快速添加**：输入框下方有固定 28px 的解析预览行（无结果时 `visibility:hidden` 占位，避免抖动）；下方三个粘性 chip（今天 / 明天 / 高优先级）作用于「下一条」，切视图时重置。
- **即时筛选条**：只改当前列表展示，**不写 Store**；切换视图重置为「全部」。
- **愿望卡片**：左侧 4px 色条 + 标题（1 行）+ 描述（2 行截断）+ 分类 · 期望日期 · 状态 chip；点卡片任意位置进入右侧编辑面板（无「保存」按钮，字段即时保存）。
- **外观预览卡**：三色块 = 该主题 `bg` / `panel` / 「当前 accent + 该主题明暗」的真实生效值；选中态用 2px 主色描边 + 序号角标（不用对勾）。

## 反模式清单（禁止）

| 反模式 | 替代 |
|---|---|
| 紫→蓝渐变 | 同色系 `color-mix(--ac, #fff/#000)` 或纯色 |
| 卡片套卡片 | 留白 + 发丝线分组 |
| 每个标题上放圆角方形图标块 | 标题本身即是识别点 |
| 到处胶囊按钮 | 控件 8–9 圆角；胶囊只用于标签/chip |
| 灰色文字压在彩色底上 | 用 `--tx` 配 wash，或加深底色 |
| 彩色底上写 `#fff` | 用 `var(--ac-ink)`（dark 近黑、light 白） |
| 扁平字号层级 | 按语义阶放大（≥1.25×） |
| 跳过标题层级 | 真实 `h1/h2/h3` |
| 拥挤 padding | 8 / 12 / 16 / 20 节奏 |
| 发光/霓虹阴影 | 中性阴影 + 内高光 |
| Inter 统治一切 | 系统字体栈 |
| 米色页面 | 中性暖灰 |
| 组件里写裸 `#hex` | `var(--…)`，颜色只在 `theme.css` 定义 |
| `[data-theme="light"]` 补丁 | 已废弃，一律 `[data-mode="light"]` |
